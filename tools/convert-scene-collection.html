Scene Collection Converter

Switch an existing Video Capture Device source to Video Capture Device (with Closed Captions), keeping its name, settings, filters, audio settings, hotkeys and every scene it appears in. Anything that refers to the source (Stream Deck buttons, Streamer.bot actions, other plugins) keeps working, because the source itself stays the same — only its type changes. You can switch it back the same way.

Everything happens in this browser window. Your file is never uploaded anywhere.

Before you start

  1. Install the Closed Caption Capture plugin.
  2. Close OBS completely. OBS saves the scene collection when it exits, which would undo the change.
  3. Open %APPDATA%\obs-studio\basic\scenes (paste it into File Explorer’s address bar). Each scene collection is a .json file named after it.
  4. Copy that file somewhere safe (for example, your Desktop) as a backup. Don’t keep the backup in the same folder: OBS lists every .json file there as a scene collection.

Video capture sources

Only one source can use a capture device at a time. If several sources use the same device, turn on Deactivate when not showing in their properties so they don’t compete for it.

After downloading

  1. Rename the downloaded file to exactly match the original (your browser may have added something like (1)).
  2. Put it in %APPDATA%\obs-studio\basic\scenes, replacing the original.
  3. Start OBS and open the source’s properties to set up its Closed Captions section.

To undo, close OBS and put your backup copy back.

Part of Closed Caption Capture for OBS. Changes exactly two values on each source you convert (id and versioned_id) and checks the result before offering it for download.
